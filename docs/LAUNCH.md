## Demonstration and source

The film is an animated worked example. Garry Tan's [September 24, 2026 public X post](https://x.com/garrytan/status/2102955139875397806), “Make software agents want”, informs a fictional booking prototype. The post was manually selected and previously verified through X's public embed endpoint. This is not a live ingestion demonstration.

The user's approval rule is hypothetical example feedback, distinct from the public source. The next task inherits that rule in the illustrated workflow. The accompanying standalone interactive demo implements the same learning loop in the current tab; it does not write to personal GBrain. No booking, revenue, real company launch, private thoughts or public-person endorsement is claimed.
