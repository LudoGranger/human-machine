# Human Machine
Build an evolving version of yourself, shaped by people you choose.

Read references/context.md for the shared evidence and memory contract.
Use the user's ordinary language. Select the action matching the request:

- Pick or change coworkers: read references/pick.md.
- Recent relevant learnings: read references/catch-up.md.
- Feedback or a draft: read references/ask.md.
- A different version beside existing work: read references/compare.md.
- Combine selected methods with the user's knowledge/voice: read references/mix.md.
- Adopt, correct or record an outcome: read references/keep.md.

Several humans may be active in a project. Writing is part of Ask, Compare and Mix. Teaching happens across all actions. No separate teach/write mode is needed.
Load only the relevant action. If the user asks for multiple related actions, compose them while preserving attribution and their selections.
This is a workflow pack using existing tools, not a running crawler or a preloaded person replica.
